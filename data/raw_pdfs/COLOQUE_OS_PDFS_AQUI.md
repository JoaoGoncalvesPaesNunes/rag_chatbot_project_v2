# Coloque os artigos cientificos nesta pasta

Copie aqui os arquivos `.pdf` que devem compor a base de conhecimento local.

Depois, no PowerShell aberto na raiz do projeto, execute:

```powershell
.\venv\Scripts\python.exe index_pdfs.py
```

Os PDFs nao sao enviados ao GitHub para preservar direitos autorais e manter a
base de cada pesquisa local.
